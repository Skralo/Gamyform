# Gamyform Implementation Plan

> Execution: native, task by task, following executing-plans; one final independent review.

**Goal:** Build the approved desktop 3D form MVP in Skralo/Gamyform.
**Architecture:** React/Vite frontend, shared validators and form state, Three.js game, Fastify API, PostgreSQL-compatible persistence.
**Spec:** docs/product-spec.md

## Global constraints
- True stationary first-person 3D, shootable choices/numbers/keyboard, original sound.
- AI drafts must use a real configured API; manual/sample fallback must be labelled.
- Single owner, versioned publish, persisted responses, safe CSV, no SaaS billing.
- Adapt selected MIT upstream source with attribution.

## Review focus
- Empty numeric input must not become zero; false must be a valid required answer.
- Repeated/ambiguous submission must not create duplicates.
- Public endpoints must never expose drafts or contacts.
- Transition and pointer activation clicks must never answer a second question.
- Stale publication/edit state must not reinterpret stored answers.
